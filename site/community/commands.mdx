title: "Commands"
description: "Every slash command the THG Community bot supports."
---

Slash commands register **per guild**, so changes appear immediately after a restart — there is no global
propagation delay. `/help` lists commands by category with a select menu.

New commands go under `src/commands/categories/<category>/` as `@Discord()` + `@Category(...)` classes. A
command without `@Category` still works but is invisible in `/help`.

## Utility

| Command | Description |
|---------|-------------|
| `/help` | Browse slash commands by category |
| `/ping` | Bot latency |
| `/info [user]` | Discord user information |
| `/profile action:view\|update` | View or refresh your community profile row |

## Linking

| Command | Description |
|---------|-------------|
| `/link` | Bind your Minecraft account to your Discord account, verified with a code |
| `/unlink [user]` | Remove your link, or anyone's (admin only for `user:`) |
| `/links` | List every linked Minecraft account (admin only) |
| `/whois <user\|username>` | Look up a link in either direction (admin only) |
| `/setrank <user> [rank]` | Set or clear the guild rank stored on a link (admin only) |

See [Account linking](/community/account-linking) for verification rules.

## Requests

| Command | Description |
|---------|-------------|
| `/request` | Submit a feature request through a short form |
| `/requestchannel set\|show` | Where feature requests are posted (admin only) |
| `/requeststatus <id> <status>` | Mark a request accepted, denied, planned, or duplicate (admin only) |

## Management

| Command | Description |
|---------|-------------|
| `/adminrole add\|remove\|show` | The Discord roles that count as bot-admin on both bots (bot admins and server admins) |
| `/setup` | One panel, a page per area: log channel, request channel, admin roles, tickets, moderation (bot admins and server admins) |

The admin-role list is **shared with TriBridge** — one list decides who is staff on both bots. See
[Shared database](/community/shared-database).

## Tickets

| Command | Description |
|---------|-------------|
| `/ticket add <user>` | Let a member into the ticket the command is run in (ticket staff) |
| `/ticket remove <user>` | Take a member back out of the ticket (ticket staff) |
| `/ticket close [reason]` | Close the ticket: transcript to the log, DM to the member (the member who opened it, or staff) |

Tickets are opened from the panel's buttons, not a command. See [Tickets](/community/tickets).

## Moderation

| Command | Description |
|---------|-------------|
| `/warn <user> <reason>` | Record a warning and DM it to the member (Moderate Members) |
| `/timeout <user> <duration> [reason]` | Time a member out for up to 28 days (Moderate Members) |
| `/untimeout <user> [reason]` | Take a timeout off early (Moderate Members) |
| `/kick <user> [reason]` | Kick a member (Kick Members) |
| `/ban <user> [reason] [delete_messages]` | Ban a member or a user id, optionally deleting recent messages (Ban Members) |
| `/unban <user> [reason]` | Lift a ban (Ban Members) |
| `/purge <count> [user]` | Delete up to 100 recent messages in the channel (Manage Messages) |
| `/cases <user>` | A member's latest 25 cases (Moderate Members) |
| `/case view\|reason\|delete <id>` | Show a case, change its reason, or delete it (delete: Administrator or bot admin) |

Every action is a numbered case in the mod log. See [Moderation](/community/moderation).
